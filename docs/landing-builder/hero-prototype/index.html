Проверяем название

Короткое название — масштаб «Кедров». Два слова: 75% базы на десктопе, 80% на телефоне. Длинные названия подстраиваются по ширине.
Проверить наполнение и переносы

Ручные строки должны повторять текст H1. Для разных экранов можно задать разные переносы. Примеры фактов демонстрационные. Правило: сверху одно короткое слово без переноса, снизу пояснение. На телефоне верхняя строка — до 20 px.
