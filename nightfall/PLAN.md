# Библиотека блоков Nightfall

Поручение: собрать блоки всех 30 отобранных страниц ОАЭ и разложить по типам, как в библиотеке Алтая. Это референсы для последующей разработки собственных эталонных блоков, не готовая сборка сайта Nightfall.

## Результат

- Отдельный маршрут `/nightfall/`, доступный через существующий GitHub Pages.
- Категории: хедер, hero, параметры, описание, архитектура/интерьеры, преимущества, галерея/видео, локация/карта, инфраструктура/wellness, планировки, оплата, инвестиции, застройщик/бренд, строительство, подбор/квиз, брошюра/CTA, FAQ, контакты/футер, другие разделы.
- Каждый вариант связан с исходной страницей и содержит десктопный и мобильный снимки либо явный статус недоступного состояния. Длинные блоки показываются целиком по частям.
- Сравнение до трёх вариантов, основной/запасной выбор, заметки, сохранение в браузере и перенос JSON. Хранилище выбора отделено от Алтая.
- Проверяемая опись всех 30 источников: число блоков, дата, ширины, ограничения, ошибка захвата при наличии. Исчезнувшие и заблокированные страницы не заменять придуманными превью.

## Исполнение

1. Синхронизировать репозиторий и изучить существующий интерфейс. Готово.
2. Снять DOM-опись источников, определить границы визуальных секций. Проверить cookie-баннеры, анимации и ленивые изображения.
3. Сохранить реальные снимки блоков на ширинах 1440 и 390; классифицировать по назначению. Дедуплицировать вложенные захваты, сохранив разные композиции.
4. Переиспользовать существующий интерфейс библиотеки с брендингом Nightfall и отдельным каталогом данных. Не изменять библиотеку Алтая и не объединять её данные с Nightfall.
5. Проверить снимки, покрытие источников, просмотр целого блока, фильтры, сравнение, выбор/импорт/экспорт и адаптивность. Визуально проверить выборку блоков и исправить неудачные захваты.
6. Обновить README/INDEX, commit + push, проверить опубликованную ссылку и открытие превью.

## Инструменты и происхождение

Без новых зависимостей: локальный Playwright 1.64.0 из существующего web-capture-toolkit, Chrome, Python/Pillow. Интерфейс основан на собственном `docs/landing-builder/block-library/`. Снимки сторонних сайтов используются как атрибутированные визуальные референсы. Коммерческие утверждения не проверяются и не переносятся в будущий шаблон автоматически.

## Уточнения владельца

- Nightfall полностью отдельно от Алтая: собственные данные, маршрут, оформление и localStorage. Файлы библиотеки Алтая не менять.
- Все пользовательские страницы открывать только во встроенном браузере этого чата. Технический захват — только headless, без окон и без действий на соседнем рабочем столе.
