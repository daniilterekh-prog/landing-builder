# Nightfall · библиотека блоков ОАЭ

[Открыть библиотеку](https://daniilterekh-prog.github.io/landing-builder/nightfall/) · [30 источников и покрытие](sources.html) · [План](PLAN.md)

Самостоятельная библиотека визуальных референсов для Nightfall · Dubai Real Estate. Данные, интерфейс, шрифты и хранилище выбора находятся в этой папке. Библиотека Алтая не изменена и не подключается.

## Как пользоваться

1. Выбери категорию слева: hero, планировки, оплата и другие.
2. Переключай десктоп 1440 / телефон 390 и фильтруй по проекту или типу источника.
3. Нажми на изображение, чтобы открыть весь блок без обрезания. Длинные секции разделены на последовательные части.
4. Отметь до трёх вариантов для сравнения рядом.
5. Выбери основной вариант категории, добавь запасные и запиши, что берём для своего блока.
6. Открой «Мой выбор» и скачай JSON. Этот файл переносит подборку между браузерами и служит заданием на следующий этап.

Локальное хранилище `nightfall.uae.block-selection.v1` принадлежит только Nightfall. Файлы выбора другой библиотеки отклоняются. Сам интерфейс работает статически, без аккаунтов и серверной базы; файл выбора сохраняй отдельно.

## Что собрано

**381 вариант, 24 категории, 31 hero, 732 доступных состояния.** Ещё 27 состояний скрыты на соответствующей ширине, 3 помечены ограничениями загрузки. Опись охватывает 30 источников на обеих ширинах.

Реальные блоки 30 отобранных страниц ОАЭ: девелоперы, агентства и посадочные из рекламы Google. Каждый вариант связан с источником. Метаданные и классификация находятся в `catalog.json`, исходные границы секций — в `captures/`, ручная правка категорий — в `classification.json`.

Категории отражают назначение блока, а не его HTML-тег. Вложенные заголовки секций не считаются самостоятельными хедерами. Два примера Salescentre принадлежат одной семье шаблонов; пары страниц одного ЖК показывают разные подачи. Первый экран квиза также доступен в hero: одна композиция выполняет две задачи.

Это библиотека для выбора и последующей разработки эталонных блоков. Экспорт JSON сохраняет подборку, а не создаёт готовый сайт.

## Ограничения захвата

- Снимки сделаны 22 октября 2026 года на ширинах 1440 и 390, deviceScaleFactor 1, Chrome / Playwright, reduced motion. Технический браузер работает без окон. Cookie-баннеры и всплывающая реклама по возможности закрыты.
- Превью — статический момент. Слайдер показывает активный слайд, FAQ — начальное состояние; все состояния каруселей и меню не перебирались. Видео и панорамы остаются доступны по ссылке на оригинал.
- В hero Object 1 браузер не декодирует видеодорожку. Для превью использован кадр 00:08 **самого исходного ролика**, установленный как постер в исходном элементе video. Это отмечено на карточке; изображение не сгенерировано и не взято из другого проекта.
- Hero Metropolitan: исходное фоновое фото возвращало HTTP 403. Карточка сообщает о недоступном визуальном состоянии; остальные секции этой страницы сохранены.
- Непрорисовавшаяся интерактивная панорама Quattro Del Mar отмечена ошибкой захвата. Пустое изображение не выдаётся за готовый вариант.
- Статусы скрытых мобильных/десктопных секций сохранены отдельно. Они не заменены вымышленными картинками.
- Формы исходных сайтов не отправлялись. Цены, доходность, сроки, юридические и визовые утверждения на снимках не проверены. Из референсов выбираем композицию и поведение, коммерческие обещания автоматически не переносим.

## Источники UI и инструменты

- Происхождение интерфейса: собственный `docs/landing-builder/block-library/` из этого репозитория, адаптация от 22 октября 2026. Копия независима от исходной библиотеки; её файлы не изменялись.
- Шрифты: Tenor Sans и Commissioner, локальные копии; лицензии OFL в `assets/`.
- Playwright **1.64.0** из установленного `web-capture-toolkit`; Chrome `/usr/bin/google-chrome`. Новые зависимости в проект не устанавливались.
- Python/Pillow для нарезки длинных снимков и миниатюр.
- Для извлечения кадра Object 1 временно использован `imageio-ffmpeg 0.6.0` / FFmpeg 7.0.2 в `/tmp`, без изменения системной установки. Ролик в GitHub не сохраняется.
- Внешние фото, оформление, названия и тексты на снимках принадлежат соответствующим источникам. Оригинальные HTML/CSS сайтов не копируются в продуктовый шаблон Nightfall.

## Обновление

Проверки интерфейса: [отчёт](checks/report.json). Они проверяют фильтры, просмотр, сравнение, выбор, перенос JSON, независимость хранилища и мобильные ширины.

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node nightfall/capture.cjs
python3 nightfall/build-catalog.py
node nightfall/check.cjs
```

`SOURCE_IDS=1,2` ограничивает перечень источников, `RECAPTURE=1` повторяет захват. Для Object 1 при повторном захвате можно указать `VIDEO_FRAME=/absolute/path/to/frame.jpg`; брать кадр 00:08 исходного URL video из DOM страницы. Если сайт не отдаёт медиа, фиксируй ограничение, не подменяй его другим проектом. Автоматическая опись не заменяет визуальную проверку границ.

Важные изменения и обновление оглавления сохранять commit + push. Для публикации достаточно существующей конфигурации GitHub Pages этого репозитория.
