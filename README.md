# Конструктор лендингов

[Оглавление](INDEX.md) · [Открыть превью](https://daniilterekh-prog.github.io/landing-builder/). Лендинги проектов и узел Алтая разделены.

Источник — приватный `barnes-sites`, сборка `docs/landing-builder/block-library/export-pages.py`. Публикуются только статические страницы, изображения, шрифты и лицензии. Для обновления повторить экспорт и commit + push в отдельный репозиторий landing-builder. Откат — revert коммита публикации; другие каталоги не затрагиваются.
